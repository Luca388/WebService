# WEEK 09 · 실습 2 구현·검증 체크리스트

최종 코드에서 1,000건의 인메모리 게시글로 확인한 결과다. API 응답과 크롬에서의 동작을 항목별로 확인했다.

| 확인 | 평가 항목 | 요구사항 | 현재 상태 |
| :---: | --- | --- | --- |
| ☑ | 검색·정렬 | 제목·본문 검색, 결과 없음 처리 | 오프셋 API에서 제목 검색 83건, 본문 검색 ID `321` 한 건, 불일치 검색 0건을 확인했다. 게시판에는 결과 없음 안내가 표시된다. |
| ☑ | 검색·정렬 | 최신순·오래된순·조회순 | 각 정렬의 1,000건을 확인했다. 최신순과 오래된순은 작성일 우선, 조회순은 조회수 우선이다. |
| ☑ | 검색·정렬 | 조회수 동점은 `id DESC` | 같은 조회수의 인접 게시글이 ID 내림차순인지 확인했다. |
| ☑ | 검색·정렬 | 잘못된 정렬 키는 `latest` 처리 | `Object.hasOwn()`으로 직접 등록한 키만 허용한다. `invalid`의 응답은 기본 최신순 목록과 같았다. |
| ☑ | 검색·정렬 | `__proto__`, `constructor` 차단 | 두 키와 `toString`의 응답이 기본 최신순 목록과 같았다. |
| ☑ | 페이지네이션 | 오프셋 페이지 이동, `meta` 응답 | 1·2페이지 목록이 달랐고, 2페이지 응답의 `page=2`, `totalCount=1000`, `totalPages=100`을 확인했다. |
| ☑ | 페이지네이션 | `page=0, -1, abc`, `limit=1000` 처리 | 세 페이지 입력은 모두 1로 처리됐다. `limit=1000`은 100건을 반환했다. |
| ☑ | 페이지네이션 | 검색·정렬 변경 시 1페이지 초기화 | 2페이지에서 각각 검색과 정렬을 바꿨을 때 요청과 화면이 1페이지로 돌아왔다. |
| ☑ | 페이지네이션 | 커서 API의 제목·본문 검색 | 화면에서 `search`를 보내며 두 API가 공통 검색 함수를 사용한다. 제목 검색과 본문 검색의 ID `321`을 확인했다. |
| ☑ | 페이지네이션 | 검색·커서 조건 적용 후 `limit + 1` | `Redis 분산 캐시`, `limit=10`에서 `cursor=128`과 `127`은 모두 10건을 반환했다. `hasNext`는 각각 `true`, `false`였다. |
| ☑ | 페이지네이션 | 커서 ID 내림차순, 정렬 기준 명시 | 커서 모드에서 정렬 선택을 숨기고 ‘ID 내림차순 고정’을 표시한다. 더 보기 후 ID `1000`부터 `981`까지 순서대로 표시됐다. |
| ☑ | 페이지네이션 | 검색어 변경 시 누적 목록·커서 초기화 | 새 검색 요청 전에 기존 목록을 지웠고, 첫 요청에는 이전 `cursor`가 없었다. |
| ☑ | 페이지네이션 | 끝까지 누락·중복 없음 | `Redis 분산 캐시` 결과 83건을 9번의 요청으로 조회해 예상 ID와 순서가 모두 일치했다. |
| ☑ | 페이지네이션 | `hasNext=false`일 때 더 보기 비활성화 | 마지막 응답에서 `hasNext=false`와 ‘더 이상 글이 없습니다’ 버튼의 비활성화를 확인했다. |
| ☑ | 비동기 | 300ms 디바운스 | `Redis`를 글자당 약 80ms 간격으로 입력했을 때 오프셋·커서 모드에서 각각 요청 1회가 전송됐다. |
| ☑ | 비동기 | 이전 요청 취소·오래된 응답 방지 | 입력 시 이전 요청을 취소한다. 늦은 응답 본문을 재현해도 `signal.aborted` 검사로 최종 결과가 유지됐다. |
| ☑ | 비동기 | `AbortError` 안전 처리 | 정상 취소 로그가 표시되고 새 요청의 결과가 정상적으로 렌더링됐다. |
| ☑ | 비동기 | 느린 네트워크에서 취소·최종 결과 검증 | 크롬에서 900ms 지연을 설정하고 검색어를 바꾸니 이전 요청은 취소됐고 화면에는 ID `321`만 표시됐다. |
| ☑ | URL 복원 | 검색어·정렬·페이지 URL 동기화 | `Redis 분산 캐시` 검색, 조회수순, 2페이지에서 주소창과 API 요청 및 화면이 일치했다. |
| ☑ | URL 복원 | 새로고침·뒤로 가기 후 URL과 화면 일치 | 검색어·정렬·2페이지와 게시글 10건이 복원됐다. 범위 밖 페이지와 미등록 정렬 키도 보정됐다. |
